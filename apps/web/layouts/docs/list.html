ArchScript language reference.

ArchScript is a small DSL for describing software architecture as code. It models systems, components, domains, environments, relations, metadata and architecture rules, then generates diagrams, documentation and reports.

Architecture Rules

Built-in architecture review

ArchScript includes a rule engine that checks architecture constraints. Rule violations do not block diagram generation, but they appear in the Playground and in PDF reports.

no_frontend_to_database

Prevents frontend elements from directly accessing database-like elements.

critical_requires_owner

Requires every element tagged as critical to define an owner property.

production_requires_monitoring

Requires production elements to define monitoring metadata. 

element service "Billing Service" as billing {
  tags [critical, production]
}

# Rule output:
# Critical element 'Billing Service' requires owner property
# Production element 'Billing Service' requires monitoring property

Exports

Generate architecture artifacts

ArchScript can export multiple artifacts from the same source model.

PlantUML

Use generated PlantUML in existing architecture documentation pipelines.

SVG / PNG

Export rendered diagrams for presentations, documentation and reports.

PDF Report

Generate a branded architecture report with diagram, documentation and review results.

Markdown

Produce text documentation that can be stored in repositories or wikis.

.archscript

Save and version your architecture source as a dedicated DSL file.

JSON Result

The compiler exposes structured output for future integrations and extensions.
